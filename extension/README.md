# BOSS 页面守卫

这是可离线加载的 Chrome 扩展。它在打开 BOSS 业务页面时自动启动，可以独立于 boss-cli 使用。

1. 如果收到的是 ZIP，先解压。打开 Chrome 的 `chrome://extensions`，开启「开发者模式」。
2. 点「加载已解压的扩展程序」，选择包含 `manifest.json` 的文件夹。
3. 打开平时使用的 BOSS 直聘页面。守卫会自动启动，工具栏面板显示连接状态、阻断的资源次数和返回 204 的上报次数。Chrome 会显示扩展正在调试标签页的提示。
4. 从旧版升级时，解压新版覆盖原扩展目录，再到 `chrome://extensions` 重新加载扩展。也可以先停用旧版，再加载新版目录。此前已经打开的 BOSS 页面在下次正常加载时应用新版页面脚本。

新文档在页面脚本运行前加载守卫。请求拦截在 Chrome 建立调试连接后开始，首次打开标签页时，连接建立前已发出的请求不会补拦。登录和安全验证页正常打开，关闭标签页或离开 BOSS 业务页面时断开调试连接。

要停止自动守卫，可在 Chrome 的扩展管理页停用扩展，然后正常刷新 BOSS 页面。点击 Chrome 调试提示上的「取消」会结束当前的请求拦截，下次加载 BOSS 业务页时会自动连接。

扩展只提供守卫功能。你可以在同一个标签页继续手动操作，或让有权限访问该窗口的浏览器操作工具按你的指令操作 BOSS。
